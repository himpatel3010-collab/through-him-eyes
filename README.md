# Through My Eyes — website

A mobile-first personal photography website built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open the `through-my-eyes` folder.
3. Open `index.html` in a browser.

For the best local experience, you can also run a simple local server:
- Python: `python -m http.server 8000`
- Then visit `http://localhost:8000`

## Deploy on Vercel
1. Create a new GitHub repository and upload the contents of this folder.
2. Import the repository into Vercel.
3. Choose **Other** as the framework preset. No build command is required.
4. Set the output directory to `.` and deploy.

## Personalise
- Replace `assets/1794215905790.jpg` with another hero photo, keeping the same filename, or change its filename in `styles.css`.
- All 53 photos and 3 videos from your ZIP are included in `assets/`.
- To change captions, edit the caption list in `script.js`.
- The gallery automatically displays all image and video files listed in `script.js`.
